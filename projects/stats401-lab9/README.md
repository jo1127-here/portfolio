# STATS 401 Lab 9 · Mapping the global economy

The [interactive lab](lab9/index.html) links a GDP choropleth and a circle cartogram for the 50 included economies. Use the country selector to highlight an economy in both views, or switch the choropleth between linear and logarithmic color scales.

The [GDP CSV](data/lab9_gdp_2025_top50.csv), [geography files](lab9/data), and [preparation script](lab9/prepare_data.py) are included.
